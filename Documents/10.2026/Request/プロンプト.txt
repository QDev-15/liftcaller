工場内のリフトの呼び出しシステム


##開発環境
	呼出元、呼出先は共にWINDOWSタブレット端末
	開発言語　C#　WPF
	データベース　必要に応じて構築　環境候補　SQL SERVER
	REST API　必要に応じて構築　IIS環境
	PLCとの連携は現時点では考えてない
	呼出元、呼出先と共に同一のWIFI環境に配置。IISが必要であれば　同一環境に配置する
	

##実装したい機能
	呼出元の端末は合計５台　１号機～５号機
	呼出側端末　１台　将来的には２～3台となるが一旦1台のみで試験的に実施
	

呼出元
	ボタン操作のみ
	ボタン種類　呼出ボタンは　「製品引取」「戻材引取」「トラブル]　の3種類
	呼出解除ボタン　呼出ボタンを解除
	
	ボタンとは別に下記の情報も見える様に
	・呼出に対する「応答中」かどうか見える
	・リフトが運転中（操業中）か停止中かが見える


呼出側
	呼出された画面は　下記の内容を読み解いて最適画面の提案をして下さい。
	操作は全てタッチ操作で行う
	
	欲しい情報と必要な機能
		・どの号機からどの理由で呼び出されたのか分かる
		・呼び出された順番
		・呼出相手に「応答中」だと知らせる方法（呼出元画面へ反映）
		・リフトが運転中（操業中）か停止中だと知らせる方法（呼出元画面へ反映）
